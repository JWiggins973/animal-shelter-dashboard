# CS340 Animal Shelter Dashboard

A web-based dashboard built with Python, MongoDB, and Dash for Grazioso Salvare 
that allows users to filter and interact with animal rescue data from the AAC shelter.

## Technologies
- Python 3
- MongoDB
- Dash / Plotly
- Dash Leaflet
- Pandas

## Files
- `crudModule.py` — Handles MongoDB CRUD operations for the animals collection
- `cs340AnimalShelterDashBoard.ipynb` — Dash dashboard with interactive table, map, and chart

## Setup
Requires a running MongoDB instance with the AAC database and animals collection loaded.
Connect using credentials defined in `crudModule.py`.
